How to verify this is genuinely cross-origin

  1. Serve this file on port 5500, not 8000.
  2. Open DevTools, Network tab.
  3. The config request shows 200 first, then 304 Not Modified on reload.
  4. The widget.js response carries Cache-Control: public, max-age=31536000, immutable.
  5. Submitting the form issues a cross-origin POST that returns 202, preceded by an OPTIONS preflight.
